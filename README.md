# 🍅 뽀모도로 타이머 🍅

인터랙티브 토마토 채움 애니메이션이 있는 뽀모도로 타이머 웹앱입니다. 집중 시간에는 토마토가 채워지고, 휴식 시간에는 커피잔이 채워지는 시각적 피드백으로 시간 관리를 도와줍니다.

## ✨ 주요 기능

### 🎯 타이머
- **작업/휴식 자동 전환** — 작업 → 짧은 휴식 → 작업 → ... → 긴 휴식 사이클 자동 관리
- **인터랙티브 SVG 애니메이션** — 작업 시 토마토 🍅가, 휴식 시 커피잔 ☕가 실시간으로 채워짐
- **물결 애니메이션** — 채움 레벨에 따라 자연스러운 파동 효과
- **자동 시작** — 페이즈 완료 후 5초 카운트다운으로 다음 페이즈 자동 시작
- **건너뛰기** — 현재 페이즈를 건너뛰고 다음으로 이동 가능

### ⚙️ 설정
- **시간 커스터마이즈** — 작업 시간 (1~120분), 짧은 휴식 (1~60분), 긴 휴식 (1~60분), 사이클 수 (1~10회)
- **빠른 프리셋** — 뽀모도로 클래식 (25/5/15), 짧은 집중 (15/3/10), 딥 워크 (50/10/30), 스프린트 (10/2/5)

### 🔔 알림음
6가지 알림음 중 선택 가능: 차임, 벨, 알람, 소프트, 디지털, 마림바
미리듣기 버튼으로 사전 확인 가능

### 📊 기록 & 통계
- **오늘의 뽀모도로 수** 및 총 집중 시간
- **이번 주 완료 수** 및 **전체 누적 기록**
- **평균 작업 시간** 통계
- 최근 30건의 완료 기록 리스트

### 🌙 다크 모드
- 시스템 설정(prefers-color-scheme)에 따라 자동 전환
- 다크 모드에서 은은한 글로우 효과

### 📱 반응형 디자인
- 모바일, 태블릿, 데스크톱 모두 대응
- 480px 이하에서 최적화된 레이아웃

### 💾 데이터 보존
- LocalStorage를 사용한 설정 및 기록 저장
- 페이지 새로고침 시 타이머 상태 자동 복원 (2시간 이내)
- 브라우저 알림 지원

## 🚀 시작하기

별도 설치나 빌드 없이 바로 사용할 수 있습니다.

```bash
# 프로젝트 클론
git clone https://github.com/corazzon/pomodoro-by-gstack.git
cd pomodoro-by-gstack

# 브라우저에서 열기
open index.html
```

또는 웹 서버로 실행:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve .
```

## 🛠️ 기술 스택

- **프론트엔드**: 순수 HTML, CSS, JavaScript (프레임워크 없음)
- **SVG 애니메이션**: 인라인 SVG + requestAnimationFrame
- **오디오**: Web Audio API (AudioContext)
- **저장소**: LocalStorage
- **알림**: Web Notifications API
- **스타일**: CSS Custom Properties (다크 모드 대응)

## ♿ 접근성

- ARIA 레이블 및 role 속성 적용
- `aria-live="polite"` 타이머 실시간 읽기
- `aria-current="page"` 활성 탭 표시
- 키보드 내비게이션 지원 (탭, 엔터/스페이스)
- 최소 터치 영역 44px 보장
