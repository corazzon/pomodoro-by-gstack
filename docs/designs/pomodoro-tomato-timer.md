## Vision

### Core Concept
멀티타이머 앱을 **뽀모도로 전용 앱**으로 전환. 토마토가 익어가는 메타포를 인터랙티브 SVG 애니메이션으로 구현.

### Platonic Ideal
사용자가 토마토가 익어가는 것을 보면서 자신의 성장을 느낌.
- 시작: 작고 녹색인 토마토
- 진행: 주황색으로 변하며 물결치는 액체가 차오름
- 완료: 빨간 토마토가 통통 튀는 바운스 + 차임
- 휴식: 따뜻한 커피컵에 커피가 차오름 + 수증기
- 누적: 헤더에 오늘 수확한 미니 토마토 카운터

## Accepted Scope

### 1. SVG 토마토 Fill 애니메이션
- 플랫/카툰 스타일 토마토 SVG (200px+, 대형)
- clip-path + requestAnimationFrame 기반 60fps fill
- performance.now() 기반 정확한 시간 추적 (백그라운드 탭 대응)

### 2. 토마토 색상 변화 (녹 → 주황 → 빨강)
- HSL interpolation으로 부드러운 그라데이션
- 0% = 녹색 (덜 익은 토마토)
- 50% = 주황색
- 100% = 완전한 빨간색

### 3. 완료 바운스 + 잎사귀 디테일
- 토마토 위에 카툰 스타일 잎사귀 SVG
- 시작 시 잎사귀 살짝 흔들림 (CSS keyframes)
- 완료 시 토마토 바운스 애니메이션

### 4. 물결 효과 (Wave Effect)
- fill 수면에 sine wave SVG path 애니메이션
- 정적 수평선 대신 살아있는 출렁임

### 5. 뽀모도로 사이클 시스템
- Work 25m → Short Break 5m → Work 25m → ... → Long Break 15m
- 반자동 전환: 5초 카운트다운 + Skip/지금 시작 버튼
- Work = 토마토 fill, Break = 커피컵 fill
- 사이클 표시: Work 1/4 ●●○○

### 6. 미니 토마토 카운터
- 헤더에 오늘 완료한 뽀모도로 수를 미니 토마토 아이콘으로 표시
- 기존 historyData에서 오늘 데이터 필터

### 7. 다크모드
- prefers-color-scheme 감지
- CSS 변수 오버라이드
- 다크모드에서 토마토 은은한 glow 효과

## Architecture

```
  SVG Renderer (NEW)              Cycle Engine (NEW)
  ├── renderTomato(progress)      ├── CYCLE_PHASES config
  ├── renderCoffee(progress)      ├── currentPhase state
  ├── fillShape(el, pct, colorFn) ├── transition logic
  ├── waveAnimation()             ├── semi-auto countdown
  └── bounceAnimation()           └── beforeunload save

  Timer Logic (MODIFIED)          Audio Engine (EXISTING)
  ├── performance.now() based     ├── Web Audio API
  ├── rAF for rendering           └── Sound presets
  └── setInterval for countdown
```

## State Machine

```
  IDLE → WORK_1 → BREAK_1 → WORK_2 → BREAK_2 → WORK_3 → BREAK_3 → WORK_4 → LONG_BREAK → DONE
                                                                                              ↓
                                                                                         (restart)
```

Timer within each phase: IDLE → RUNNING ↔ PAUSED → FINISHED

## Design Decisions

| Decision | Choice | Reasoning |
|----------|--------|-----------|
| 토마토 스타일 | 플랫/카툰 | 귀여운 캐주얼 느낌, 접근성 높음 |
| 토마토 크기 | 대형 200px+ | 토마토가 주인공, 몰입감 |
| 휴식 비주얼 | 커피컵 + 수증기 | Work/Break 시각적 구분, 따뜻한 느낌 |
| 앱 방향 | 뽀모도로 전용 | 정체성 확립, 집중된 경험 |
| 사이클 전환 | 반자동 (5초 + Skip) | 사용자 통제감 유지 |
| 백그라운드 탭 | performance.now() | 정확한 시간 추적 |
